# My Journey — Gautam Kumar

A responsive personal website with Home, About, Journey, Blog, Gallery and Contact sections.

## Publish on GitHub Pages
1. Create a GitHub repository named `my-journey`.
2. Upload all files and folders from this package.
3. Open Settings → Pages.
4. Under Build and deployment, select “Deploy from a branch”.
5. Choose `main` and `/ (root)`, then Save.
6. GitHub will provide the public website URL.

## Customize
- Replace gallery placeholders with your photos.
- Update social links in `index.html`.
- Add blog pages in the `blog` folder.
